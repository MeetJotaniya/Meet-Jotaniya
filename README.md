> **Machine Learning · Python · Scikit-learn · Pickle**

📄 PDF to MCQ Generator
Deep Learning · NLP · Python · Ollama · Phi-3

- Built an automated pipeline that converts PDF documents into multiple-choice questions.
- Used the Phi-3 model locally through Ollama without any external API dependency.
- Applied NLP techniques for context extraction, question generation, and distractor creation.
- Designed the system for educational content generation and self-assessment workflows.

---

🎓 Student Project Management System (SPMS)
Next.js · Prisma ORM · Neon PostgreSQL · RBAC

- Built a full-stack Student Project Management System using Next.js for both frontend and API routes.
- Used Prisma ORM with Neon (serverless PostgreSQL) for database modeling and efficient query handling.
- Implemented project tracking, student–mentor assignment workflows, and project progress management.
- Designed role-based access control (RBAC) for Students, Mentors, and Administrators.
- Developed responsive dashboards with secure authentication and authorization.
